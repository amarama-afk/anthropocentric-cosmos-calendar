# Anthropocentric Cosmos Calendar (ACC)

**ACC** is a versioned, forward-counting calendar that places everything — from the Big Bang to human history to the far future — on one honest, linear timeline.

It extends the spirit of the **Holocene Era (HE)** calendar (adding 10,000 to Gregorian years for clean forward-counting) by anchoring to the cosmological origin while keeping human intuition intact.

- Counts forward from **0 ACC** at the Big Bang.
- Anchored to **Planck 2018** (13.797 ± 0.023 Gyr) for the current epoch (ACC-Planck18).
- Present (early 2026): **13 797 312 026 ACC ±0** (index label exact by convention).
- Physical mapping uncertainty: ±~23 Myr (1σ) when interpreted as years since origin.
- Evolves via **epoch tags** (e.g., ACC-PlanckXX) when better data arrives — head updates, mnemonic tail stays stable.
- Uncertainty-first: Displayed precision never exceeds evidence.

### Why ACC?
- One real axis: No compression, no artificial precision, no backward counting.
- Future-proof: Works linearly for billions of years ahead.
- Human-centered: Stable tail mnemonic (~300 kyr sapiens → ~10–12 kyr Holocene → 2026 echo).
- Complements HE: Recent history uses 12026 HE = current ACC tail.
